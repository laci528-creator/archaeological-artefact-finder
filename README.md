# English

## Archaeological Artefact Finder

A full-stack web application for searching and exploring archaeological and historical objects from public museum collections.

The application uses the Metropolitan Museum of Art Collection API to retrieve object data and presents the results in a responsive React interface. Selected artefacts can also be stored as favorites and managed through the application's backend.

## Features

- Search for archaeological and historical objects
- Display search results in responsive cards
- View detailed information about individual objects
- Pagination with 20 results per page
- Save selected artefacts as favorites
- Remove saved favorites
- Add personal notes to saved artefacts
- Database-backed favorite storage
- Loading animation with a themed hourglass
- Error handling for unavailable or incomplete API data
- Responsive navigation
- Museum-inspired visual design

## Technologies

### Frontend

- React
- Vite
- React Router
- JavaScript
- CSS

### Backend

- Node.js
- Express.js

- Database integration

### External API

- Metropolitan Museum of Art Collection API

## Project Purpose

This project was created as a portfolio project to combine my background and interest in archaeology with modern web development.

The main goal was to practice building a full-stack application with React and Node.js while working with an external API, asynchronous data requests, backend routing, pagination, database storage and error handling.

## Installation

Clone the repository:

git clone https://github.com/laci528-creator/archaeological-artefact-finder.git

Use the database/init.sql file to create the required database structure.

Install the required dependencies for the frontend and backend and configure the necessary environment variables before starting the application.

# Deutsch

# Archaeological Artefact Finder

Eine Full-Stack-Webanwendung zur Suche und Erkundung archäologischer und historischer Objekte aus öffentlichen Museumssammlungen.

Die Anwendung verwendet die Collection API des Metropolitan Museum of Art, um Objektdaten abzurufen und die Ergebnisse in einer responsiven React-Oberfläche darzustellen. Ausgewählte Objekte können außerdem als Favoriten gespeichert und über das Backend der Anwendung verwaltet werden.

## Funktionen
- Suche nach archäologischen und historischen Objekten
- Darstellung der Suchergebnisse in responsiven Karten
- Anzeige detaillierter Informationen zu einzelnen Objekten
- Seitennavigation mit 20 Ergebnissen pro Seite
- Speichern ausgewählter Objekte als Favoriten
- Entfernen gespeicherter Favoriten
- Hinzufügen persönlicher Notizen zu gespeicherten Objekten
- Datenbankgestützte Speicherung der Favoriten
- Ladeanimation mit einer thematisch passenden Sanduhr
- Fehlerbehandlung bei nicht verfügbaren oder unvollständigen API-Daten
- Responsive Navigation
- Vom Museum inspiriertes Design
